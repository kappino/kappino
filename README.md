I write `C/C++` firmware for STM32 and ESP32, secure IoT pipelines, and build ROS 2 and Python systems. I use a small Proxmox homelab to test networking and TLS.

- [**CARE**](https://kappino.me/projects/proj-care-decision-planner) — Built the ROS 2 planner (`durable_rules` → GoRules JDM) that prioritizes medication reminders and measurements over optional activities on an assistive robot.
- [**SortEdge Bin**](https://kappino.me/projects/proj-munnisc-cestinno) — Led a team of eight and wrote STM32/ChibiOS firmware for a waste-sorting prototype with ~13 ms on-device CNN inference.
- [**TNES**](https://kappino.me/projects/proj-tnes) — Co-built the FastAPI backend connecting an Unreal Engine 5 simulator to Cisco Modeling Labs (*1st place, Hack the Route @ The Big Hack 2026*).
- [**SPECTRA**](https://doi.org/10.1007/978-3-032-33874-7_13) — First author of an exploratory wearable EEG study published in Springer LNNS and finalist for the IAS-19 Best Student Paper Award.
